# 🤖 FAQ Chatbot

A simple AI-powered FAQ chatbot built with Python, Streamlit, and scikit-learn.

## 📌 Project Overview

This project is an FAQ chatbot that accepts user questions and finds the most relevant answer from a predefined FAQ knowledge base.

The chatbot uses **TF-IDF vectorization** and **cosine similarity** to compare the user's question with available FAQ questions.

## ✨ Features

- Interactive Streamlit web interface
- Predefined FAQ knowledge base
- Custom user questions
- TF-IDF text vectorization
- Cosine similarity matching
- Automatic fallback response for unknown questions
- Simple and beginner-friendly implementation

## 🛠️ Technologies Used

- Python
- Streamlit
- scikit-learn
- TF-IDF
- Cosine Similarity
